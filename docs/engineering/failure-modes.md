# Failure modes and effects analysis

Status: written 2026-10-15, refreshed 2026-10-15 UTC (issue 51) after PRs #108 to #113 and #123. Format follows [Azure failure mode analysis](https://learn.microsoft.com/en-us/azure/well-architected/reliability/failure-mode-analysis).
Severity and Likelihood are my ratings (High, Medium, Low) for this local project. They are not measured.
"Gap" means that I found no mitigation or no test in the repo. I did not invent one.
"Excluded on purpose" means that the user decided to leave the feature out for local-only operation ([ADR-0028](../adr/0028-server-production-features-excluded.md), spec Q157). The risk is real if the server leaves the local machine.

## Gaps found

Covered by a test since the first version (each row cites the test; the emulator and Compose runs are recorded only in PR descriptions or comments, with no committed result file, which is a Gap): backward-clock delay (row 6, ADR-0025), database stopped and `/health` versus `/ready` (row 11, ADR-0026), real airplane mode, real full disk, and real WorkManager failure (rows 1, 9, 14, ADR-0029), SDK and server validator drift (row 10, ADR-0027).

Excluded on purpose, not forgotten ([ADR-0028](../adr/0028-server-production-features-excluded.md)):
- No server rate limit and no `429` (row 5).

Still open:
1. Power loss is not observed. The semantics are documented and the setting is pinned (rows 2, 9, ADR-0029). The cost of `synchronous=FULL` is not measured.
2. No monotonic clock; a forward clock jump sends one batch early; a WorkManager request made before a jump is not tested on a device (row 6).
3. The Compose restart policy was not shown to trigger. No alert and no metrics endpoint (rows 4, 11).
4. A request-level 400 still holds the entire queue. This is intended for contract bugs, but a third-party client or a JSON syntax error can still cause it (row 10).
5. No separate ingest and query budgets (row 17).
6. `Retry-After` is a fixed 1 second (row 4).
7. The contract retirement policy is not built on the server: no `Deprecation` or `Sunset` headers, no traffic count, no threshold value (row 13).
8. The device fault tests ran on one emulator image and CI does not run them (rows 1, 9, 14).
9. Rejected options for Room and the Worker path are not recorded ([design-review.md](design-review.md)).
