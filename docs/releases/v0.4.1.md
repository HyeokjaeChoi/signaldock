# SignalDock v0.4.1

Patch release of the Android SDK. License: Apache-2.0 ([LICENSE](../../LICENSE)). No breaking change from 0.4.0. The public API is the same, and the runtime dependency tree is the same. See the [changelog](../../CHANGELOG.md).

## What is included

- The Maven repository ZIP `signaldock-sdk-android-0.4.1-maven.zip` and its `.sha256` file. The coordinate is `local.signaldock:sdk-android:0.4.1`. Maven Central is not used. See [Add the SDK to an app](../../README.md#add-the-sdk-to-an-app).
- A build provenance attestation for the ZIP ([ADR-0039](../adr/0039-release-provenance-attestation.md)).
- The source of the repository, as in the tagged commit.

Verify the download from the folder that holds both files:

```sh
shasum -a 256 -c signaldock-sdk-android-0.4.1-maven.zip.sha256
```

Verify the attestation (GitHub CLI 2.102.0 or newer):

```sh
gh attestation verify signaldock-sdk-android-0.4.1-maven.zip --repo HyeokjaeChoi/signaldock \
  --signer-workflow HyeokjaeChoi/signaldock/.github/workflows/release.yml
```

The command must exit 0.

## What changed in the SDK

- Import order and one unused import in five source files, from the new ktlint rule set ([ADR-0049](../adr/0049-production-quality-gates.md) A2). The compiled behavior is the same.
- `sdkVersion` and `SDK_VERSION` are `0.4.1`. Events collected after the update carry `sdkVersion` `0.4.1`. Events that 0.4.0 queued keep their stored version.

No public API change: the diff of `sdk/sdk-android/api` against `v0.4.0` is empty. No runtime dependency change: the diff of `sdk/sdk-android/dependencies` against `v0.4.0` is empty.

## What changed in the repository

CI gates of ADR-0049: nightly workflow, Android Lint, detekt, StrictMode and power-loss device checks, semver check of the API dumps, coverage ratchet, OSV-Scanner, Renovate validation, `main` ruleset as code, ingest load SLO, image scan. This release is the first one that runs the release gate: the `build` job fails unless the last `nightly.yml` run on the tagged commit is `success` ([`scripts/check-nightly-green.sh`](../../scripts/check-nightly-green.sh)). These gates do not change the AAR.

## Upgrading from 0.4.0

Change the version: `implementation("local.signaldock:sdk-android:0.4.1")`. No server change and no code change is needed.

## What was not verified

- A physical device with the 0.4.1 SDK. The device records ran with 0.2.0 and 0.3.0 ([README, Limitations](../../README.md#limitations)).
- Release signing and Play distribution ([ADR-0009](../adr/0009-maven-zip-and-consumer-app.md)).
- The attestation, until the release workflow has run. Record the result in the release issue.
