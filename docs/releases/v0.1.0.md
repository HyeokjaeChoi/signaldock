# SignalDock v0.1.0

First tagged release. License: Apache-2.0 ([LICENSE](../../LICENSE)).

## What is included

- The Maven repository ZIP `signaldock-sdk-android-0.1.0-maven.zip` and its `.sha256` file. The coordinate is `local.signaldock:sdk-android:0.1.0`. Maven Central is not used. See [Add the SDK to an app](../../README.md#add-the-sdk-to-an-app) and [ADR-0009](../adr/0009-maven-zip-and-consumer-app.md).
- The source of the Android SDK, the server, the Dashboard, the demo app, the consumer app, and the measurement harnesses, as in the tagged commit. See the [repository guide](../../README.md#repository-guide).

Verify the download from the folder that holds both files:

```sh
shasum -a 256 -c signaldock-sdk-android-0.1.0-maven.zip.sha256
```

Requirements of the AAR: `compileSdk` 36 or newer, `minSdk` 24 or newer, Kotlin 2.2 or newer, AGP 9.x ([README](../../README.md#add-the-sdk-to-an-app)).

## What was verified

- The ZIP is built by `scripts/verify-consumer.sh`. The script unzips it into a clean folder, checks that the AAR Kotlin metadata is 2.2 or lower, and builds the independent consumer app as an R8 release from that folder only ([README, step 3](../../README.md#3-sdk-maven-zip-and-the-independent-consumer-app), [ADR-0009](../adr/0009-maven-zip-and-consumer-app.md)).
- Server load: two pilot runs and one overload run on one Mac with Docker limits, in `perf/results/`. The overload run shows HTTP 503 with `Retry-After` and recovery without a restart ([README, Scope and verification](../../README.md#scope-and-verification)).
- SDK on emulators: normal, offline, and burst runs on API 24 and API 37 with a debug build, and once more on API 37 with an R8 release build (debug-signed), in `perf/sdk-results/summary.md` ([ADR-0014](../adr/0014-sdk-device-measurement-harness.md), [ADR-0018](../adr/0018-sdk-release-r8-measurement.md)).

The numbers are local environment records, not an SLA.

## What was not verified

- Physical devices. SDK measurement and the `adb reverse` route ran on emulators only ([README, Limitations](../../README.md#limitations)).
- The 216-run server pool-size matrix (Q133, [ADR-0013](../adr/0013-server-load-measurement-harness.md)).
- Release signing and Play distribution. The consumer app uses the debug key ([ADR-0009](../adr/0009-maven-zip-and-consumer-app.md)).
- A consumer on a Kotlin version other than the AGP 9.3.3 default (2.2.10), or on AGP 8.x ([ADR-0009](../adr/0009-maven-zip-and-consumer-app.md)).
- Public internet operation. The stack is local only ([README, Limitations](../../README.md#limitations)).
