## Scope and completion criteria

Spec Q168. The decisions are in ADR-0040. The user approved the item on 2026-10-17 UTC.

1. The SDK AAR ships a Baseline Profile (`baseline-prof.txt` at the AAR root) for the SDK hot paths: `initialize()`, `track()`, the Room queue, the sender. The profile holds `local.signaldock.**` rules only. It is generated by the `androidx.baselineprofile` Gradle plugin and committed (`sdk/sdk-android/src/main/generated/baselineProfiles/baseline-prof.txt`).
2. The generator is `sdk/baseline-profile` (a `com.android.test` module with `BaselineProfileRule`). It drives the new sample app `sdk/profile-app`, which uses the SDK as a normal dependency. Command: `sdk/gradlew -p sdk :sdk-android:generateBaselineProfile` with one booted emulator or device.
3. The published runtime dependency tree does not change (`dependencyGuard` passes with no baseline change). The public API does not change (`apiCheck` passes).
4. The effect is measured on the API 37 emulator `faults37` with Macrobenchmark: `CompilationMode.None()` against `CompilationMode.Partial(BaselineProfileMode.Require)`, and a control without the SDK rules. The raw files are in `perf/sdk-results/baseline-profile-api37/`.
5. The APK size budget (ADR-0023) still passes.
6. Docs: ADR-0040, spec Q168, `TOOLCHAIN.md`, the README performance section, `CHANGELOG.md` [Unreleased], `docs/design-index.md`.
